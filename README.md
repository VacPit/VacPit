# `05` — ENGINEERING PHILOSOPHY

### `01` — PRODUCT > CODE

Code is a tool.

The goal is to create something people actually need.

### `02` — AUTOMATE THE REPETITIVE

If a process can be automated, it should be.

### `03` — DESIGN FOR SCALE

An MVP should be able to evolve into a production system without rewriting everything from scratch.

### `04` — KEEP IT SIMPLE

Good architecture is not about making a system complicated.

It's about making complexity manageable.
