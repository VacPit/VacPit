## Как работаю

1. Присылаете вводные — за 20 минут говорю цену и дату или отказываюсь.
2. ТЗ на одну страницу: что входит, что нет, срок, сумма. Всё письменно.
3. Предоплата 50%, старт. Промежуточный результат — по договорённости.
4. Сдача: работает на вашей стороне, акт, остаток. Три недели гарантии на баги.

Секреты в `.env`, в репозиторий не попадают. Код остаётся у вас, с инструкцией по запуску.
